## ✨ Key Features

- **✂️ Millisecond Precision Trimming:** Enter start and end timestamps or use the interactive timeline slider.
- **🎯 100% Watermark-Free:** Clean MP4 downloads with no ads or intrusive branding added.
- **🎥 Multiple Resolution Choices:** Supports **1080p Full HD**, **720p HD**, **480p SD**, and **360p**.
- **🏷️ Dynamic File Naming:** Downloads are automatically labeled with the original video title and cut timestamps (e.g., `Video-Title-0115-0230.mp4`).
- **📱 Fully Responsive:** Works seamlessly on iPhone (iOS Safari), Android (Chrome), Windows, macOS, and Linux.
- **🔒 No Sign-up & Privacy First:** No account or credit card needed. Files are temporarily processed and purged automatically.

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Processing Core:** `yt-dlp` & `ffmpeg`
- **Frontend:** HTML5, Modern CSS (Glassmorphism design tokens), Vanilla JavaScript
- **SEO & Structured Data:** Schema.org (`WebApplication`, `FAQPage`, `BreadcrumbList`), OpenGraph protocol
